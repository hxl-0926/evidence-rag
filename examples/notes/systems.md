# Engineering notes

SQLite transactions commit related writes atomically or roll them back together.
Idempotency keys prevent a retried request from applying the same change twice.
Optimistic concurrency rejects an update when a record version has changed.

# Evaluation

Recall measures how much relevant evidence was retrieved.
Mean reciprocal rank rewards placing the first relevant result early.
Evaluate retrieval on held-out questions rather than only the examples used during development.
